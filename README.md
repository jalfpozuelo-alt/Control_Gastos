# Control Gastos v4

Versión móvil de Control Gastos.

Cambios:
- Icono PWA renovado.
- Indicador de ritmo con verde / amarillo / rojo.
- Estado de «Hoy» en verde o rojo según el presupuesto diario.
- Nueva categoría «Supermercado».
- Gastos por categoría ordenados de mayor a menor.
- Gráfico de barras en gastos por categoría.
- Navegación de categorías mejorada.
- Cabecera azul opaca para evitar efectos visuales de iOS.
- Service Worker actualizado para forzar la nueva versión.
